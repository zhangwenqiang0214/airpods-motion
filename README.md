# AirPods Motion

在 macOS 上实时读取 AirPods 的头部姿态，配 3D 人头预览、引导式校准和陀螺仪零偏测量。

> **EN** — Read AirPods head-tracking motion on macOS. Live 3D head-pose preview,
> a guided four-step axis calibration, and a gyro-bias measurement tool.
> Swift + SwiftUI + SceneKit, no dependencies. Data stays in memory.

![3D 头部姿态预览](head_preview.png)

## 环境要求

- macOS 14 或更新
- 支持头部追踪的 AirPods（Pro / Max / 第三代及以后）已连接
- Xcode 命令行工具

## 构建与启动

```bash
./build.sh
```

构建完成后，**从访达双击 `AirPodsMotion.app` 启动**。

> ⚠️ 不要在终端里运行。macOS 的权限系统会把终端认作发起方，
> 找不到运动权限声明，进程会被直接终止。

首次点「开始」时会弹出「想要访问运动与健身数据」，选允许。
之后可在 系统设置 › 隐私与安全性 › 运动与健身 里随时撤销。

## 使用

点「**开始**」采集。顶部显示采样率和累计帧数，中间的 3D 人头会实时跟随你的头部姿态。

### 引导校准（⇧⌘K）

首次使用建议跑一遍。四步，每步都要手动确认，程序不会自己往下走：

| 步骤 | 动作 |
|---|---|
| 1 | 坐正，看向屏幕正前方（3 秒倒计时，结束时的朝向记为零点） |
| 2 | 慢慢低头看键盘 |
| 3 | 慢慢把头转向左边 |
| 4 | 把头歪向右肩 |

后三步的动作幅度到位并保持约 1 秒即可，屏幕上有进度条提示。
校准结果会保存，下次启动自动沿用。

按 Esc 可随时退出校准。

### 重设零点（⌘K）

只重做第一步。换个坐姿、或者觉得人头朝向偏了，按这个即可，不用重新走全套校准。

### 陀螺仪零偏测量（⌘D）

测量偏航角的漂移速率。

**戴着耳机测量，不要摘下来** —— 耳机一旦离耳，运动数据流会立刻中断。

坐正，尽量别动头，静置至少 3 分钟。界面会显示三个轴各自的漂移率（°/min）
并给出可信度判断。俯仰和侧倾有重力作为参照、基本不漂，因此它们的读数
可以当作对照：如果它们几乎不动而偏航持续单向爬升，那个爬升就是陀螺仪零偏。

偏航没有绝对参照（AirPods 没有磁力计），本来就会随时间漂移——这也是
「重设零点」存在的原因。

## 快捷键

| 快捷键 | 功能 |
|---|---|
| ⇧⌘K | 引导校准 |
| ⌘K | 重设零点 |
| ⌘D | 陀螺仪零偏测量 |
| Esc | 退出校准 |

## 读数说明

| 读数 | 含义 |
|---|---|
| Pitch 俯仰 | 抬头 / 低头，单位度 |
| Roll 侧倾 | 左右歪头，单位度 |
| Yaw 偏航 | 左右转头，单位度 |
| 用户加速度 | 已扣除重力分量，单位 G。静止时接近 0 |
| 角速度 | 单位 rad/s |

## 常见问题

**打不开，提示无法验证开发者**
从访达右键点 app 选「打开」，或到 系统设置 › 隐私与安全性 里点「仍要打开」。

**采样率一直是 0**
- 确认耳机已连接、且是当前的音频输出设备
- 确认已授予运动权限（系统设置 › 隐私与安全性 › 运动与健身）
- 界面显示「等待首帧」属正常，通常 2 秒内到达；超过 20 秒会自动重连，
  也可以点「立即重连」

**测量中途显示「数据流中断」**
多半是耳机被摘下、进入休眠或蓝牙断开。戴回去会自动恢复，中断期间不计入统计。

**人头的转动方向反了**
跑一遍引导校准（⇧⌘K），轴向由实测动作决定。

**漂移测量提示「结果不可信」**
头部晃动太大。找个头靠、坐稳，重新测。

## 隐私

传感器数据只在内存中使用，不写入磁盘，不做任何网络请求。
应用只申请运动权限一项。
